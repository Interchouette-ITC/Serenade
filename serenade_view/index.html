HTML view helpers: reverse routing, assets, partials, and document composition.

Escape stays in serenade_form; this crate re-exports it for one import surface. Document composition is engine-neutral; template engines can integrate without becoming mandatory dependencies of this crate. The optional leptos-ssr feature renders complete documents under a request-scoped Leptos owner and injects managed metadata. The leptos-client feature exposes the head root and lifecycle components used by CSR/hydrated apps. Compatible AOT compilers can target these components without becoming dependencies of this crate.
