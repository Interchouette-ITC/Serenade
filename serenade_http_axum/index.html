Axum bridge for serenade_http.

Convert Axum/HTTP requests into Serenade Request values, run a kernel (HttpKernel sync or AsyncHttpKernel), then map the Serenade response back to Axum. Same four-step bridge as the Actix adapter.

App skeletons that only need “bind and serve the kernel” can call listen with an AsyncHttpKernel (use from_sync for sync controllers) instead of wiring axum::serve by hand.

§Examples

use serenade_http::Response;
use serenade_http_axum::to_axum;

let response = to_axum(&Response::text(200, "ok"));
assert_eq!(response.status(), 200);
