Wasmer WASIX host helpers.

Serenade owns engine plumbing. Product apps own package URLs, guest ABIs, and fixtures. FrameworkBundle does not register this crate.

Enable Cargo feature wasix (default).

Cache root: env SERENADE_WASMER_CACHE, else a relative .wasmer next to the calling crate’s manifest when products wrap this helper.
