Actix-web bridge for serenade_http.

Convert Actix requests into Serenade Request values, run a kernel (HttpKernel sync or AsyncHttpKernel), then map the Serenade response back to Actix. An Axum adapter can follow the same shape without changing the foundation crate.

Typical sync handler:

ⓘ
async fn healthz(
    request: HttpRequest,
    body: web::Bytes,
    kernel: web::Data<HttpKernel>,
) -> HttpResponse {
    dispatch(kernel.get_ref(), &request, body)
}

App skeletons that only need “bind and serve the kernel” can call listen with an AsyncHttpKernel (use from_sync for sync controllers) instead of wiring HttpServer by hand.

§Examples

use serenade_http::Response;
use serenade_http_actix::to_actix;

let response = to_actix(&Response::text(200, "ok"));
assert_eq!(response.status(), 200);
