OpenAPI document helpers and optional explorer UI mounts for Serenade apps.

Apps still declare their own #[derive(OpenApi)] paths and schemas. This crate owns path conventions, Info/servers helpers, and (behind feature actix) mounting Swagger UI, Redoc, RapiDoc, and Scalar beside a Serenade HTTP kernel.

See docs-dev/OPENAPI.md.
