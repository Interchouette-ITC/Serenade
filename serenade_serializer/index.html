DTO serialization: JSON codecs, optional TOON, normalizer registry, serde bridge.

Typed serde helpers cover the common JSON path. Custom types register Normalizer / Denormalizer implementations on a NormalizerRegistry (or via Serializer). Enable Cargo feature toon for TOON v4.1 LLM export.
