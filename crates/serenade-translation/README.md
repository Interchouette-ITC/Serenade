# serenade-translation

Internationalization and localization for Serenade applications.

Framework-owned `Translator`, TOML-first message catalogues, locale negotiation, and
ICU format helpers. Product-specific multilingual data stays in the application.

Part of [Serenade](https://github.com/Interchouette-ITC/Serenade); most applications
depend on the [`serenade-framework`](https://crates.io/crates/serenade-framework) facade.
API documentation: <https://docs.rs/serenade-translation>.
