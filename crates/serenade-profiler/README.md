# serenade-profiler

Web debug toolbar and per-request profiler for Serenade HTML applications
(Symfony `web_profiler` analogue).

Enable it only in development.

Part of [Serenade](https://github.com/Interchouette-ITC/Serenade); most applications
depend on the [`serenade-framework`](https://crates.io/crates/serenade-framework) facade.
API documentation: <https://docs.rs/serenade-profiler>.
