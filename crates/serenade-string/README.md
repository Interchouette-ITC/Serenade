# serenade-string

Slug, case transforms, and English inflector helpers (Symfony String shaped).

Functions: `slug`, `snake_case`, `camel_case`, `pascal_case`, `kebab_case`,
`title_case`, `pluralize`, and `singularize` (English rules with documented limits).

Part of [Serenade](https://github.com/Interchouette-ITC/Serenade); most applications
depend on the [`serenade-framework`](https://crates.io/crates/serenade-framework) facade.
API documentation: <https://docs.rs/serenade-string>.
