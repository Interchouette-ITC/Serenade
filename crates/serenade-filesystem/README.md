# serenade-filesystem

Path helpers, dump/mirror, and temp file utilities (Symfony Filesystem shaped).

Functions include `exists`, `mkdir`, `remove_tree`, `dump_file`, `append_to_file`,
`read_to_string`, `copy`, `mirror`, `temp_dir`, and `temp_file`.

Part of [Serenade](https://github.com/Interchouette-ITC/Serenade); most applications
depend on the [`serenade-framework`](https://crates.io/crates/serenade-framework) facade.
API documentation: <https://docs.rs/serenade-filesystem>.
