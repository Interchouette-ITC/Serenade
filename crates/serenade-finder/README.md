# serenade-finder

Directory walking with name glob and type filters (Symfony Finder shaped).

`Finder` configures the root (`in_path`), file or directory selection, name globs,
depth, and dotfile handling; `Finder::collect` returns sorted matching paths.

Part of [Serenade](https://github.com/Interchouette-ITC/Serenade); most applications
depend on the [`serenade-framework`](https://crates.io/crates/serenade-framework) facade.
API documentation: <https://docs.rs/serenade-finder>.
