Source
Expand description

AuthN/Z hooks: users, tokens, voters, HTTP firewall, CSRF, password hashing, and session login bridge.

Optional feature oauth adds OAuth 2.0 / OIDC relying-party helpers (not an authorization server). Optional feature ldap adds directory bind helpers (apps own the LDAP client). Apps plug bearer or API-key authenticators into FirewallMiddleware. CSRF uses HmacCsrfTokenManager (stateless HMAC). Password hashing uses Argon2idPasswordHasher. Session stickiness for HTML logins uses login / SessionTokenMiddleware. See docs-dev/SECURITY.md.
