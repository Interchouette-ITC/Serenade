Console Application: Symfony bin/console analogue.

Plain commands use clap for argv (--env, --no-debug). Interactive mode (--interactive) uses rustyline for ↑/↓ history. Debug surfaces may use ratatui (see DebugContainerCommand, DebugConfigCommand).
