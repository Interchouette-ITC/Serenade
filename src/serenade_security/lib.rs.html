1//! AuthN/Z hooks: users, tokens, voters, HTTP firewall, CSRF, password hashing,
2//! and session login bridge.
3//!
4//! Optional feature `oauth` adds OAuth 2.0 / OIDC relying-party helpers (not an
5//! authorization server). Optional feature `ldap` adds directory bind helpers
6//! (apps own the LDAP client). Apps plug bearer or API-key authenticators into
7//! [`FirewallMiddleware`]. CSRF uses [`HmacCsrfTokenManager`] (stateless HMAC).
8//! Password hashing uses [`Argon2idPasswordHasher`]. Session stickiness for HTML
9//! logins uses [`login`] / [`SessionTokenMiddleware`]. See `docs-dev/SECURITY.md`.
