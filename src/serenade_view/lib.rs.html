1//! HTML view helpers: reverse routing, assets, partials, and document composition.
2//!
3//! Escape stays in [`serenade_form`]; this crate re-exports it for one import surface.
4//! Document composition is engine-neutral; template engines can integrate without
5//! becoming mandatory dependencies of this crate. The optional `leptos-ssr` feature
6//! renders complete documents under a request-scoped Leptos owner and injects managed
7//! metadata. The `leptos-client` feature exposes the head root and lifecycle components
8//! used by CSR/hydrated apps. Compatible AOT compilers can target these components
9//! without becoming dependencies of this crate.
10
