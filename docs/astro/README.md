# Serenade documentation site

The public documentation is built with Astro and Starlight. Its content is authored in Markdown
in this directory; existing framework guides are loaded from `../../docs-dev` during development
and production builds, rather than maintained as a second copy.

## Commands

```sh
npm ci
npm run dev
npm run build
npm run preview
```

The production build targets `/docs/` on `https://serenade.rs`. Deployment is not configured
here: the intended `/docs/` and `/api/` paths require a combined artifact on the confirmed
official domain.

Rust API reference remains generated by `make doc`; see [`../api-rust/README.md`](../api-rust/README.md).
