# Serenade documentation site

The public documentation is built with Astro and Starlight. Its content is authored in Markdown
in this directory; existing framework guides are loaded from `../../docs-dev` during development
and production builds, rather than maintained as a second copy.

## Commands

```sh
npm ci
npm run dev
npm run build
npm run preview
```

The build publishes every site page and the original developer guides as
Markdown under `dist/markdown/` independently of the MCP. The homepage's MDX
cards are converted to Markdown headings. A build test checks page coverage
and file hashes. No Rangular checkout is required. To additionally publish Rangular
documentation, explicitly set `RANGULAR_DOCS_DIR` to a Rangular `docs`
directory; missing inputs then fail the build. The generated
`markdown/index.json` lists each file and its SHA-256 hash.
Set `SERENADE_DOCS_REV` and `RANGULAR_DOCS_REV` to record source revisions
when known. These are declared build inputs; file hashes identify the actual
published bytes even when a checkout has local changes.

The configured site URL is `https://docs.serenade.rs`. Deployment and Markdown
MIME mapping are not configured here; the static host must serve `.md` files as
`text/markdown`. Astro preview does so.

Rust API reference remains generated by `make doc`; see [`../api-rust/README.md`](../api-rust/README.md).
