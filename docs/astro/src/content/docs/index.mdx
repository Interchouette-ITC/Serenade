Serenade takes inspiration from Symfony’s component architecture and builds it for Rust. Cargo
manages dependencies; your application composes the framework pieces it needs.

## Two documentation layers

- **These guides** explain architecture, workflows, and practical use.
- **[Rust API documentation](https://interchouette-itc.github.io/Serenade/)** is generated from
  source with `make doc`; see the [API documentation guide](./reference/api-docs/) to build it
  locally.

The examples are deliberately distinct: the bundle sample explains application composition;
the HTML, SPA, SSG, and Universal examples demonstrate different front-end modes.
