The examples demonstrate separate framework capabilities and front-end modes. Start with the
smallest example that matches your question.

| Example | Best for | Run |
| --- | --- | --- |
| [`demo-app`](https://github.com/Interchouette-ITC/Serenade/tree/dev/examples/demo-app) | Bundles, DI, config, console commands, routes, and events | `make demo` |
| [`demo-html`](https://github.com/Interchouette-ITC/Serenade/tree/dev/examples/demo-html) | Server-rendered HTML, forms, CSRF, and an Actix adapter | `make html` |
| [`demo-monorepo`](https://github.com/Interchouette-ITC/Serenade/tree/dev/examples/demo-monorepo) | Shared Leptos UI in SPA and SSG modes | `make spa` or `make ssg` |
| [`demo-universal`](https://github.com/Interchouette-ITC/Serenade/tree/dev/examples/demo-universal) | Frontend plus a running Serenade backend | `make universal` |

The samples are intentionally small and do not claim every crate is production-ready. Read each
example README for exact prerequisites, outputs, and environment settings.
