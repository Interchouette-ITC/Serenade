Start with the bundle tutorial to run Serenade's canonical sample, trace its real source, and
make a small configuration change. It uses the current workspace instead of pretending Serenade
crates are already published.

- [Build your first bundle application](./first-bundle-app/)

The sample is a console composition demo, not an HTTP server. Continue with
[the web-mode guide](../first-steps/choose-your-mode/) to run the HTML, SPA, SSG, or Universal
examples.
