# Rust API documentation (rustdoc)

From the repository root, run `make doc` to build the Rust API documentation locally.
Then open `docs/api-rust/serenade_kernel/index.html`; `docs/api-rust/index.html`
redirects there.

The documentation workflow publishes generated rustdoc to the `gh-pages` branch,
but no canonical hosted URL is approved. The docs site links to this guide until
that URL is confirmed.
