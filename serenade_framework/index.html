§Serenade

Serenade is a Symfony-oriented application framework for Rust: a kernel with bundles, a dependency-injection container, an event dispatcher, layered configuration, and optional components (HTTP, security, messaging, views, forms, …) that applications compose.

serenade-framework is the public entry point for normal Serenade consumers. It re-exports a curated, stable surface of the serenade-* implementation crates. Those crates stay independently published and usable; the facade never owns their implementation.

Website: https://serenade.rs. Guides: https://docs.serenade.rs.

[dependencies]
serenade = { package = "serenade-framework", version = "1.0.0" }

The package rename imports the crate as serenade instead of serenade_framework (cargo add serenade-framework --rename serenade).

The executable named serenade is shipped by the separate serenade-cli package. The crates.io package serenade is unrelated to this project.

§Features

The default build contains only the framework foundations (kernel, config, di, event). It needs no web server, database, Leptos, or Rangular.

Integration features (*-reqwest, *-smtp, *-esp, *-oauth, *-ldap, view-leptos-*, scheduler-messenger) are never implied by their base feature.

Crates outside this surface (for example serenade-cache, serenade-workflow, serenade-translation, serenade-testing) are used directly by depending on them.

§Example

use serenade::prelude::*;

struct Shop;

impl BundleInterface for Shop {
    fn name(&self) -> &'static str {
        "shop"
    }
}

let mut app = App::new(Environment::Test);
app.register_bundle(Shop).expect("register");
app.boot().expect("boot");
assert_eq!(app.kernel().bundle_names(), vec!["shop"]);
app.shutdown().expect("shutdown");
